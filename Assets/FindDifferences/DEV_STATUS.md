# 1. 当前版本

- 玩法：上下布局的「大家来找茬」（上 = 原图 A，下 = 修改图 B），点击不同处，错点扣时，有提示次数。
- 开局先选模式：
  - **A 通关模式**：每关独立计时（关卡 `timeLimit`，统一 60 s），按顺序打完全部关卡后显示「恭喜，您已通关！」并回到模式选择；超时可重新挑战或返回。
  - **B 生存模式**：总时间 `survivalTime`（180 s），每过一关 +`survivalBonusPerLevel`（10 s），过关后直接进入下一关；关卡用完后从第一关继续（新一轮）。时间用完或点「结束」后显示成绩（通过关数 / 找到不同数 / 坚持秒数），最佳纪录存在 PlayerPrefs（`fd.survival.bestLevels / bestDiffs`）。成绩通过 `FindDifferencesGame.SurvivalEnded` 事件发出，供今后接入排行榜。
  - **测试关卡**：按 `releaseLevels`（正式版关卡数组）的顺序逐关试玩，规则同 A 模式（每关独立计时，从第一关开始，不随机、不受 `startLevel` 影响），顶栏显示「测试 N/总数」，打完后显示「测试关卡已全部完成」。
  - `releaseRange`（Vector2Int，x = 起始编号、y = 结束编号，含两端；按关卡资源名中的编号匹配，如 Level170 = 170，从 A 模式 `levels` 列表中按其顺序取出）+ `releaseFromRange`（bool）：勾选后 `releaseLevels` 自动由 `levels` 中该范围的关卡生成（Inspector 中修改即生效，运行时 Awake 也会再生成一次），手动编辑的列表会被替换；不勾选则按手动编辑的 `releaseLevels` 使用。当前为 `releaseRange = (265, 344)`、`releaseFromRange` 勾选，即正式版关卡 = Level265～344（80 关）。
  - A/B 各有关卡数组和「随机顺序」开关（`campaignRandomOrder / survivalRandomOrder`）：开启后每轮内每关只出现一次，下一轮重新打乱（新一轮第一关不会与上一轮最后一关相同）。
- 场景：`Assets/FindDifferences/Test77.unity`，对象 `FindDifferencesGame` 的 `levels`（A 模式）列表当前 **593 关**（Level06～Level135 + Level500～509 + Level136～344 + Level510～519 + Level520～619 + Level1000～1009 + Level1500～1623，按场景顺序见第 4 节；500 起为新编号段，1000 起为背景卷轴循环系列，1500～1509 为写实风格系列、1510～1514 为卡通渲染系列、1515～1519 为写实夜色哥特（月光 god ray）系列、1520～1529 为写实风景 / 静物第三组、1530～1531 为墨线轴测系列、1532～1537 为同视角的写实 / 卡通渲染 / 美漫轴测系列、1538～1541 为铅笔素描系列（45° 俯视 3D 与普通 2D 各 2 关）、1542～1544 为卡通渲染童话系列、1545～1564 为第 1～5 关的四种渲染复刻（卡通 / 写实 / 美漫 / 素描各 5 关），1565～1584 为写实暗黑奇幻系列（哥特猎人之城 / 陨落王国各 10 关），1585～1594 为卡通渲染 JRPG 系列，1595～1604 为写实开放世界都市系列，1605～1614 为美漫桌游奇幻冒险系列，1615～1619 为高对比校园 RPG 风格系列，1620～1623 为写实暗黑奇幻 Level1569 / 1571 / 1573 / 1574 的卡通渲染版，Level136～344 使用 500 之前的空余编号、追加在列表末尾；资源名不连续不影响游戏内「第 N 关」，它按场景顺序计数）；`survivalLevels`（B 模式）当前与 A 相同。

# 8. 画面风格规范（新关卡必须遵守）

## 8.1 基础风格：纸艺（paper-craft）

- 所有物件是「剪纸片」：`paper.piece(c, shapes, col, border, shadow)` —— 白色切边（`PAPER_WHITE`）+ 柔和投影；细节贴片用 `flat()`（无边无影）。
- 常用投影参数（kit.py）：`PROP=(2,4,7,0.42)` 物件，`SMALL=(1,2,3,0.3)` 小件，`LAYER=(1,3,11,0.36)` 大景片（山丘、地面层）。
- 景深用「分层景片」：天空渐变 → 远山（`layer()` / `hill_strip()`）→ 中景建筑 → 地面 → 前景人物/道具；远层颜色更淡、更偏天色。
- 所有图片最终做纸纹后处理 `post=paper_post`（含暗角）。特殊风格关可用 `oil_post / sketch_post / tiltshift_post / neon_post / anime_post`。
- 配色：明亮柔和、饱和度中等；暗场景（恐怖 / 夜景）可用 `paper25` 的 `edge_mix` 让切边随物体变色，避免发光白边。

- **写实风格**（levels_real，Level1500～1509）：唯一不用纸艺切边的系列。生成需要 numpy（其余模块仍为纯 Python）。背景函数里 `g = Ctx(c)` → 绘制 → `g.commit()`；形状用 `real.Box / Ell / Circ / Poly / Seg / Under(曲线以下) / Rough(噪声轮廓)` 及 `| - &` 组合，颜料用 `vgrad / lgrad / rgrad / tex / grain_tex / light_x / light_y / sphere_paint / cyl_paint` 或 `(X, Y) -> rgb` 函数；`g.mul` 软阴影、`g.add / g.glow` 加光、`g.fog` 雾带、`g.reflect` 水面倒影、`g.blur` 景深、`g.bloom` 泛光、`g.grade` 调色；动画元素用 `real.el(fn)` 包装（`real_kit` 的 `cloud_el / mist_el / bird_el / smoke_el / glint_el / fall_el`），雨雪复用 `weather.rain_layer / snow_layer(mask=0)`。噪声只取决于场景坐标，A/B、测量画布与元素画布结果一致；随机数用固定种子且不随 d 改变调用次数。**倒影 / 镜面只反射未修改状态**：先用 `set()` 画一遍上半景 → `g.snapshot()` → 再用 d 重画（见 l1500 / l1506），否则倒影会让不同处变成两块、判定圈过大或出现 stray px。不同处避免带大面积光晕 / 整辆车 / 整把伞换色（判定圈会超过 100 px），改为紧凑的小件增删或局部换色；每关先按 3×2 网格分散布置 6 个候选。
- **写实夜色哥特 + 月光 god ray**（levels_real2，Level1515～1519）：沿用写实系列全部规则。光源为月亮（室外在画面内，室内在窗外画面外），背景统一由 `make_bg(scene, rays)` 构建：d 非空时先画一遍未修改场景 → `snapshot` 作为体积光来源，再画带不同的场景，最后 `g.godrays(...)`；这样 A / B 的光束完全一致，不同处不会因光束而扩大或出现 stray px。`godrays` 为屏幕空间径向模糊：取快照中亮于 `threshold` 且位于 `region`（室外 = 天空区域，室内 = 窗洞形状）的像素，沿指向光源的方向累加衰减（`density / decay / samples`），被城堡、枝桠、窗棂、蝙蝠遮挡处自然形成暗缝；`receive` 控制受光范围（`moon_receive()` 防止月面过曝，室内可让光束在地面附近淡出）。要让光束「有形」，必须让遮挡物压在光源前（主塔压住月亮、枝桠横过月面、窗棂 / 铁栅）。动态部分：`beam_el()` 沿光束方向的柔和光柱慢速呼吸（用普通覆盖填充，只会提亮）、`motes_el()` 光束中的浮尘、`bat_el()` 飞行蝙蝠、`flame_el()` 烛火；室内地面光斑按光源方向投影窗形（`l16_pool`）。原创吸血鬼 `vampire()`（立领披风、红衬里、徽章、可持玫瑰，月光轮廓光 `rim()`）；不血腥（无血迹、无獠牙特写、无骷髅）。
- **写实风景 / 静物第三组**（levels_real3，Level1520～1529）：沿用写实系列规则。背景构建器三选一：`flat_bg(scene)`（无倒影无光束）、`two_pass(upper, lower)`（水面关：上半景先按未修改状态画一遍 → `snapshot` → 再按 d 画，`lower` 里 `g.reflect` 只反射未修改状态）、`levels_real2.make_bg(scene, rays)`（god ray 关：珊瑚礁的水面阳光、森林瀑布的林冠阳光、厨房的窗光）。水中小船不进倒影快照，用 `boat_hull()` 自带的模糊倒影块。透视田垄（薰衣草 / 葡萄园）用「屏幕 x 偏移 ÷ 距地平线距离」得到收拢的行，远处混入雾色以避免摩尔纹。候选不同的判定圈通常 r = 40～70，按「圈边到圈边 ≥ 135 px」布置时要比纸艺关更分散（每关 6～7 个候选，measure 后若只选出 3 处，按 `diff_stats.json` 的圈心 / 半径挪位置再 select）。
- **墨线轴测**（levels_inkiso，Level1530～1531）：白纸 + 蓝色圆珠笔排线（`INK`），点缀红墨（`RED`：旗、灯笼、篷布、渔网）与淡蓝水彩（`WASH`：水面、阴影晕）。所有物体用世界坐标（米制格）建模后经 `Iso.p` 投影；绘制顺序按深度 `x·sin35° + y·cos35°` 由远及近（在前方的大物体如防波堤必须后画）。凹陷（水渠）的内壁、水面都要与开口 `Inter` 裁切，否则会像凸起的墙。顶面保持留白（只在暗时排线），竖直面用近竖直排线，阴影统一向画面右侧。排线 / 抖动只由场景坐标与固定种子决定，A / B 一致。不同以整件增删、红墨换色为主；小于 400 px 的小件（围巾、小旗）要放大或换成更大的物件。

- **铅笔素描**（levels_sketch，Level1538～1541）：只用石墨灰（`LEAD`）画在暖白纸（`PAPER` + 纸纹）上，不用颜色。明暗 = 淡涂抹（smudge）+ 排线，暗部加交叉排线（`tone()`）；轮廓用 `Outline`（形状 SDF 的抖动描边带，主线 + 一条错位淡线，`outline()`）；直线用 `line()`（出头 + 第二笔）。2D 关直接用 `sk(g, shape, 明度, seed, 排线角, grad=(x0, x1, 增量))` 画每个物件；45° 关用 `Sketch` 画风套 `levels_isostyle` 的几何工具。排线要长而连续（`brk` 低、`seg` 长），否则大面积会出现“迷彩”斑块；碎石等叠加的地面贴花先铺纸色再画，避免重叠处变深。不同以增删 / 形状变化为主（圆钟换方钟、风景画换肖像、帽子有无），小件要放大到 ≥ 500 px。
- **前 5 关四画风复刻**（levels_remake，Level1545～1564）：每个场景只写一次（`harbour / autumn / picnic / town / underground`），通过统一的 2D 画风接口（`sky / obj / flat / shadow / water / ground / line / glow / finish`）交给四个画风类渲染：`ToonS`（toon.py 的 `cel`）、`RealS`（光照渐变 / 球面着色 + 材质纹理 + 软阴影 + 颗粒）、`ComicS`（粗黑描边 + 平涂 + 网点阴影月牙）、`SketchS`（levels_sketch 的石墨明暗 + 抖动描边）。不同的主题与原关一致（云、屋顶、灯塔条纹、帆、鱼、浮标；热气球、松树、窗灯、风车、蘑菇、兔子；锦鲤、三明治、飞盘、花、蚂蚁；屋顶、遮阳伞、停车、小船、树、长椅；蚂蚁、胡萝卜、蚯蚓、Zzz、宝箱、化石）。**换色类不同在素描版里只剩明暗差**：换色时要同时拉开亮度（例：红屋顶换成浅黄而不是同亮度的蓝），素描的细节填充用交叉排线区分深浅；素描版的 `glow` 画两圈淡铅笔环（否则只有光晕的元素会是空的）。

- **电子游戏内容 第 6 组**（levels_gamecontent6，Level225～234）：同前几组规则；下落消除类用圆形果冻 `jelly()`，**不使用四格方块骨牌的外形与 10×20 井**（避免与知名方块游戏的受保护外观相似）；新增 `thug()` 卡通混混、`fruit()`、`mole()`、`ship()` 俯视帆船、`island()`、`dino()`（long / horn / rex，描边卡通）。
- **任意主题**（levels_mix1～11，Level235～344）：侧视纸艺 / 室内正面，夜景关用 `npiece()`；辅助函数见 10.6。大面积物件（整排花田、整条彩虹、整座高架桥、整面遮阳篷）不要整件换色——判定圈会超过 170 px 拟合范围，只改其中一段 / 一个桥墩 / 一块牌子。
- **勇者与恶龙**（levels_dragon，Level170～174）：纸艺侧视 / 室内正面；原创角色 `hero()`（刺猬头 + 披风，剑 side/up）、`mage()`、`healer()`、`elder()`、`king()`、`princess()`、`slime()`、`chest()`，以及 `dragon()`（stand / fly / sleep 三种姿势，可左右朝向，`pk=dpiece` 用于暗场）；夜间 / 洞穴关用 `dpiece()`；不血腥（无骷髅、无伤口）。
- **现代 / 秋叶原**（levels_akiba）：`modern()` 人物、`maid()`、`sign_box()` 竖排招牌（用随机笔画代替文字）、`chibi()` 手办；**不使用真实品牌、商标或现有角色**。
- **格斗游戏风格**（levels_misc）：原创格斗家（`fighter_gi / fighter_kungfu / wrestler`）+ 顶部血条 / 七段数字倒计时 HUD；**不复刻任何版权角色**。

# 9. 关卡设计规则

- 画面 900×600（纹理像素，左上为原点绘制；`Difference` 资产里为左下原点，由生成器转换）。
- **满幅构图**：不得有大片空白天空 / 地面 / 墙面。远景补山、林、城市天际线、云带；前景补道具、植物、人物；室内补墙饰、家具；纯色区域不能透出画布黑底（天空渐变需覆盖到建筑缝隙）。
- **每关实际使用 3～5 处不同**。关卡代码里可以写更多「候选」（通常 7 处），由 `diff_select.py` 选出符合规则的 3～5 处（见 10.3）；类型以「颜色改变 / 物件增减 / 形状变化」为主，分散在画面各处。
- 不同的大小：每处变化像素 **≥ 400**（约 20×20 px 以上）；更小的候选不会被选用，应改为整件变色或整件增删。
- **任意两处不同的判定圈之间至少隔开画布宽度的 15%（135 px，圈边到圈边）**，不能重叠或相邻。
- 一个元素同时画多处不同时（例如室内整张前景贴图），用 `fdcore.on("id", m)` 代替 `m` 分别判断，否则这几处只能一起保留或一起舍弃。
- 不同处**不能被动态元素长期遮挡**：漂移云要限制在不同处上方的高度带；烟雾、飞鸟只做短暂经过；夜间才出现的元素（忍者、光晕）不放在不同处上。
- 不同处尽量放在**静态背景**中；放在动画元素上时用 `variant=True` 且动作幅度小（如轻微摇摆）。
- 夜间元素用 `daynight="night"`；发光物（火、灯）用 `"untinted"`；雾 / 云在昼夜关中改为 `"tinted"`，否则夜里会变成亮白块。
- 人物尺寸：侧视前景人物缩放 `h≈1.0–1.8`（约 45–80 px 高），主角可放大；不要让关键人物小于 40 px。
- 每关时限统一 60 秒（`fdcore.LEVEL_TIME_LIMIT`，关卡模块里写的时限不再生效）；动画时长 `anim_seconds` 与昼夜周期（40 s）或天气总时长对齐。
- 昼夜周期统一 40 s；天气步长 5～12 s、过渡 `blend=3.0`。
- 版权：只用公共领域题材或原创设计；现代场景不出现真实品牌。

# 10. 工具与生成流程

## 10.1 目录

- `Scripts/`：`FindDifferencesGame.cs`（游戏流程 / UI / 调试按钮）、`DifferencePicture.cs`（图片、元素动画、昼夜 / 天气着色、环绕镜头）、`FindDifferencesLevel.cs`（关卡 ScriptableObject、ElementAnim、DayNight / Weather / Orbit 数据）。
- `Art/`、`Levels/`：生成的图片与关卡资产（勿手改，改生成脚本后重新生成）。
- `Tools~/`（Unity 不导入）：Python 生成器。

## 10.2 生成器

```
cd Assets/FindDifferences/Tools~
python generate_assets.py Level123            # 生成指定关（资产写入 Art/ 与 Levels/）
python generate_assets.py Level123 --preview=<目录>   # 同时输出 A/B 对照预览并做自动核对
python generate_assets.py Level123 --anim=<目录>      # 输出动画 APNG
```

- 关卡定义：每个模块导出 `LEVELS = [(name, title, background(c, d), elements, diffs, time_limit, opts), ...]`，在 `generate_assets.py` 中 import 并加入 `ALL_LEVELS`。
- `background(c, d)`：`d` 为 B 图中生效的不同 id 集合，用 `"xxx" in d` 切换 A/B 内容。
- `diffs`：`(id, x, y, r)`；**`r=0` 表示自动拟合**（按 A/B 实际差异像素计算判定圈，搜索半径 170 px）——新关一律用 0，只有纯动画差异才手填半径。
- `elements`：`fdcore.E(id, draw(c, m), bbox=None, pivot=None, anim, animB, show="both|A|B", variant, daynight, weather)`。
- opts：`post`、`day_night=dict(period, phase, tint)`、`weather=dict(steps=[(TYPE, sec)...], blend, tints)`、`anim_seconds`、`frames`、`custom`（自定义构建器，如环绕镜头）。
- 资源 GUID 固定：`md5("FindDifferences/" + 相对路径)`，重复生成不会改变引用。

## 10.3 选择不同（diff_select.py）

```
python diff_select.py measure [LevelXX ...]   # 逐个候选单独测量（判定圈、像素数、由哪个元素绘制）-> diff_stats.json
python diff_select.py select [LevelXX ...]    # 按规则选出 3～5 处 -> diff_selection.json（不足 3 处时自动加「换色」不同）
python diff_select.py verify                  # 检查已生成的 Levels/*.asset（数量、间隔，环绕镜头关按每个视角）
```

- `generate_assets.py` 生成关卡时读取 `diff_selection.json`：只保留选中的不同（用测量出的判定圈，不再重新拟合），只画了被舍弃不同的元素在 A/B 中变为一致（`neutral`），`auto` 为换色不同。不在该文件中的关卡保持代码里的全部不同。
- 修改关卡的候选不同后：`measure` + `select` 该关，再重新生成。
- Level28（环绕镜头）不经过此流程，使用的不同在 `levels_orbit.py` 的 `USED28` 中手动指定（三个视角下都需满足间隔）。

## 10.4 自动核对（每次生成必看）

预览运行会打印：`check LevelXX: id=像素数 ...`
- 出现 `!! N stray px in [box]` = 有不在任何判定圈内的差异 → 修正（通常把该处改为 `r=0` 或调整提示点）。
- 某 id 为 `0` = 该不同在静态画面中看不见（被遮挡或只存在于动画）→ 检查绘制顺序 / 位置。
- 像素数过小（< ~150）→ 加大变化。
- 生成后需看预览图（A/B 上下拼接，B 图画出判定圈）确认构图与遮挡；有昼夜 / 天气的关再看动画帧。

## 10.5 加入场景

把 `Levels/LevelXX.asset` 的 GUID（`fdcore.guid_for("Levels/LevelXX.asset")`）追加到 `Test77.unity` 中 `FindDifferencesGame` 的 `levels:` 列表末尾（`- {fileID: 11400000, guid: <guid>, type: 2}`）；如该关也用于生存模式，同样追加到 `survivalLevels:` 列表末尾。不要改动 `startLevel / debugMode` 及两个随机开关的现值。
- `diff_select.py` 只读取 `levels:` 到 `startLevel:` 之间的 GUID（A 模式列表），所以脚本里这两个字段须保持名字和相邻顺序；只放在 `survivalLevels` 里的关卡不会被它处理。

# 11. 扩充新关卡的检查清单

1. 选定主题 → 选视角（默认侧视纸艺；系列内保持同一视角风格）。
2. 新建或沿用对应模块，复用第 10.5 节的共享库，保持比例与配色一致。
3. 构图满幅，安排 5～7 处分散、清晰的候选不同（`r=0`，每处 ≥ 400 px，彼此相隔 ≥ 135 px）。
4. 加入 2～6 个与主题相符的动态元素；需要时加昼夜或天气。
5. `diff_select.py measure / select` 该关 → `--preview` 生成，确认核对无 `!!`、`verify` 通过；查看预览图与动画帧。
6. 把关卡 GUID 追加到 `Test77.unity` 的 `levels` 列表末尾（diff_select 以该列表为准）。
7. 在本文件第 4.1 节表格追加一行，并更新「当前版本」中的关卡总数。
